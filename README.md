# Dice Simulator

A simple Python program that simulates rolling one or more dice and tracks the number of rolls.

## Features
- Roll one or multiple dice
- Generate random dice values
- Track roll count
- User-friendly command-line interface

## Technologies Used
- Python 3
- Random module

## How to Run

1. Clone the repository
2. Open terminal
3. Run:

python dice_simulator.py

## Example Output

Enter number of dice: 2

Roll 1:
Dice 1: 4
Dice 2: 6

Roll again? (y/n)
